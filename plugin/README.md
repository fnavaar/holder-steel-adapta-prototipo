# Variante candidata — construção por módulos
Conteúdo instrucional pronto para carregar explicitamente, não instalado automaticamente. Não trocar settings do plugin global. Identificar repo/branch/version do plugin alvo e testar roteamento antes de promover.
Ler skills/construir-por-modulos/SKILL.md e testar com testes-protocolo.json. Estes casos são roteiro de aceite da variante, não provas de execução do Maestro. Instruções podem orientar agente que tenha carregado o repo, mas não criam tools/handlers/capacidades inexistentes.
